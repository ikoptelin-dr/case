# Шаблон репозитория команды

Подарок участникам ROИИ 2026 к докладу «Как избежать корпоративной AI-посредственности». Евгения Одуд, t.me/productodud.

Это тот самый репозиторий со слайда, только пустой и с подсказками. В нём всё, чтобы выйти из чатика: главный файл с правилами для агента, папки с контекстом, проверки качества для AI и правила работы с AI для команды.

## Что внутри

| Файл или папка | Что там |
|---|---|
| `interview.md` | Интервью: агент задаёт вопросы по одному и сам раскладывает ответы по файлам. Начните с него |
| `AGENTS.md` | Главные правила: кто мы, цели, клиенты, как работаем с AI и где что лежит. Читает каждый агент и каждый человек |
| `CLAUDE.md` | Одна строка: подключает `AGENTS.md`, чтобы у Claude Code и Codex были одни правила |
| `company/` | Продукт, цели, клиенты, журнал решений |
| `functions/` | Как мы работаем: маркетинг, поддержка, продукт. По файлу на функцию |
| `markets/` | Только то, чем рынок отличается |
| `evals/` | Проверки качества для AI: реальные задачи и правильные ответы |
| `team/` | Правила работы с AI в команде, ретро репозитория, журнал изменений |
| `archive/` | Закрытые проекты. AI читать нельзя |
| `prompts.md` | Готовые просьбы к агенту: заполнить, обновить после встречи, разобрать ошибку, проверить перед отправкой |
| `.claude/skills/interview/` | То же интервью командой `/interview` в Claude Code. Папка скрытая: на Mac её показывает сочетание Cmd, Shift и точка |

## Три слоя

- **AI знает всегда:** `AGENTS.md`. Кто мы, куда идём, что нельзя. Агент читает этот файл в начале каждой сессии, поэтому он короткий.
- **AI ищет по запросу:** `company/`, `functions/`, `markets/`, `evals/`, `team/`. В `AGENTS.md` есть карта, и агент открывает файл, когда он нужен для задачи.
- **AI не видит никогда:** `archive/`, черновики и личные данные.

## С чего начать

1. **Скопируйте папку** и назовите её под команду или процесс.
2. **Пройдите интервью с агентом.** Откройте папку в Claude Code или Codex и напишите: «Давай заполним репозиторий». Агент задаст вопросы по одному, покажет, что запишет, и сам разложит ответы по файлам. Это 30–40 минут, можно частями. Если есть презентация, стратегия или описание продукта, дайте их агенту в начале: вопросов станет меньше.
3. **Утвердите `team/ai-rules.md` вместе с командой.** Черновик агент подготовит в интервью, обсудить его можно за полчаса: что AI делает сам, что решает человек, кто что проверяет и что считаем хорошим результатом.
4. **Начните с одного процесса.** Опишите его в `functions/` и соберите 10–20 задач в `evals/`. Остальное заполняйте, когда понадобится.
5. **Поставьте в календарь ретро репозитория:** раз в неделю, 30 минут. Повестка в `team/retro.md`.

Дальше работать удобно с готовыми просьбами из `prompts.md`.

## Как подключить

- **Codex.** Откройте папку и запустите Codex. Он сам читает `AGENTS.md`.
- **Claude Code.** Откройте папку и запустите Claude Code. Он читает `CLAUDE.md`, а тот подключает `AGENTS.md`.
- **Пока только чат.** Создайте проект в ChatGPT или Claude, вставьте `AGENTS.md` в инструкции проекта, а нужные файлы из папок загрузите в проект. Это ещё не агент, но уже не пустой чатик. Интервью работает и здесь: загрузите `interview.md` и напишите «Проведи интервью по interview.md». Файлы чат не сохранит, готовый текст копируйте сами.

## Как поддерживать

Контекст живёт, пока его поддерживают. Три церемонии:

- **Ретро репозитория**, раз в неделю: что решили, где AI ошибся, что работает. Правки сразу в репозиторий.
- **Записи встреч**, каждый день: отдаёте агенту запись звонка, он предлагает правки в контекст, человек их утверждает.
- **Разбор ошибки**, когда AI ошибся: ошибка становится правилом в репозитории и новой задачей в `evals/`.

У репозитория есть владелец, а все изменения записаны в журнал. Удобнее всего хранить папку в git: тогда журнал ведётся сам. Если git пока нет, записывайте изменения в `team/changelog.md`.

## Чего не делать

- **Не кладите сюда личные данные, пароли, ключи и договоры.** `AGENTS.md` просит агента не читать `archive/`, но это просьба, а не замок. Что AI не должен видеть никогда, в репозиторий не кладём вовсе.
- **Не заполняйте всё за один день.** Пустой раздел лучше выдуманного.
- **Не берите чужие шаблоны не читая, этот тоже.** Прочитайте и поправьте под себя.
